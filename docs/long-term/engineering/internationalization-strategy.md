# 国际化策略

## 范围

- 支持语言固定为 `zh_cn` 与 `en_us`。
- 不提供模组内独立语言切换入口，始终跟随玩家当前游戏语言。
- 当玩家语言不是 `zh_cn` 或 `en_us` 时，统一回退到 `en_us`。

## 行为约定

- 界面文案、命令反馈、快捷键名称与 Mods 列表描述统一使用语言文件。
- `Mods` 列表模组名称固定为 `Infinite Inventory / 无限库存`，描述通过 `fml.menu.mods.info.description.infiniteinventory` 覆盖。
- 搜索与名称排序按当前查看者语言构建。
- 搜索额外兼容另一套支持语言的显示名别名。
- 中文名称额外提供拼音全拼与首字母检索。
- 玩家自定义页签名、玩家自定义物品名不做自动翻译。

## 维护规则

- `zh_cn.json` 作为主维护源，`en_us.json` 必须保持键集完全一致。
- 新增玩家可见文本时，必须优先落到 `lang`，禁止在界面代码里直接写中英文文案。
- 搜索索引相关改动必须同时验证：
  - 当前语言显示与排序正确
  - 双语别名检索仍然可用
  - 中文拼音检索未退化
